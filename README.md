# 🧮 React Calculator

A simple and responsive calculator built using **React.js, JavaScript, HTML, and CSS**.

## ✨ Features

* Addition, subtraction, multiplication & division
* Clear and delete functionality
* Dynamic result calculation
* Responsive UI

## 🛠️ Tech Stack

* React.js
* JavaScript
* HTML
* CSS
* Vite

## 🚀 Run Locally

```bash
npm install
npm run dev
```

## 📚 Concepts Used

* React `useState`
* Event Handling
* Conditional Logic
* State Management
